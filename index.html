DisputeFlow
Dispute Document Processing System

Full-stack event-driven system that automates dispute document processing across multiple bank portals — solving a real operational problem faced by fraud investigators daily. Architected with multi-bank per-thread-pool processing, bank-specific filename parsing, reason code mapping (AMEX S01, PMTC 98), and a rules-based decision engine for auto-classification.

Integrated Kafka for async event streaming with graceful fallback polling for production cost constraints. Deployed on DigitalOcean with Docker, Nginx, and Let's Encrypt SSL. Built a React frontend with real-time upload status. Roadmap includes RBAC, per-investigator credential vault, and a manager analytics dashboard.
